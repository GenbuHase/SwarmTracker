# ウィジェット想定レイアウト

埋め込み・トップページ共通の presence 表示。カード多用は避け、**1行〜短いブロック**で「いまどこか」だけ伝える。

## 状態一覧

| 状態 | 条件 | 見せ方 |
|---|---|---|
| **Here** | `visible: true` | Stack レイアウト（下記 B）。場所名 + 地域 + **チェックイン時刻** |
| **Away** | `visible: false`, `reason: "disabled"` | 非公開である旨のみ |
| **Unknown** | `visible: false`, `reason: "no_public_checkin"` | `共有されていません`（下記） |
| **Loading** | 取得中 | スケルトン / 「…」 |
| **Error** | API 失敗 | 控えめなエラー（場所は出さない） |

## バリアント

### A. Compact（推奨・埋め込み向け）

ブログやプロフィール横に置く一行型。

```text
┌─────────────────────────────────────────┐
│  ● 朝霞駅 (TJ12)           7/11 22:51  │
└─────────────────────────────────────────┘
```

- 左: 状態ドット（Here=ティール、Away=グレー）
- 中央: 会場名（長いときは省略）
- 右: **ローカル絶対時刻**（狭ければ `M/D HH:mm`）
- Away: `● 非公開` + `Off`

### B. Stack（**Here の本表示・単独ページ向け**）

採用する Here 表示。縦積みの短いブロック。

```text
┌──────────────────────────┐
│  ● NOW                   │
│  朝霞駅 (TJ12)           │
│  埼玉県朝霞市・日本      │
│  ──────────────────────  │
│  7/11 22:51にチェックイン │
└──────────────────────────┘
```

| 行 | 内容 | API 由来 |
|---|---|---|
| ラベル | 状態ドット（Compact と同じ）+ `NOW` | 固定 |
| タイトル | 会場名 | `venueName` |
| サブ | `{state}{city}・{country}` | `state` + `city` + `country` |
| フッタ | **ローカル絶対時刻** + 「にチェックイン」 | `checkedInAt` + `timeZoneOffset` |

#### 時刻表示ルール（Here）

- 表示は Swarm の `timeZoneOffset`（分）で換算した**現地ローカル時刻**を使う（閲覧者のブラウザ TZ に引っ張らない）
- Stack 例: `7/11 22:51にチェックイン`
- Compact 例: `7/11 22:51`
- 相対時刻（「2時間前」）は初期は出さない。必要なら後から `（2時間前）` を併記可
- 日付が「今日」の場合の短縮（`今日 22:51`）は実装時の任意最適化

### Away（採用）

**Compact**

```text
● 非公開                              Off
```

**Stack（採用）**

```text
┌──────────────────────────┐
│  ● OFF                   │
│  非公開                  │
│  ──────────────────────  │
│  現在公開されていません  │
└──────────────────────────┘
```

| 行 | 内容 |
|---|---|
| ラベル | 状態ドット + `OFF`（Here の `NOW` と対になる） |
| タイトル | `非公開` |
| サブ | 出さない |
| フッタ | `現在公開されていません` |

Unknown（On だが表示対象なし）は下記。

### Unknown（採用）

**Compact**

```text
● 共有されていません                    —
```

（ドット色は Here のティール / Away のグレーとは別のアンバー系）

**Stack**

```text
┌──────────────────────────┐
│  ● PRIVATE               │
│  共有されていません      │
│  ──────────────────────  │
│  公開記録がありません    │
└──────────────────────────┘
```

| 行 | 内容 |
|---|---|
| ラベル | 状態ドット + `PRIVATE` |
| タイトル | `共有されていません` |
| サブ | 出さない |
| フッタ | `公開記録がありません` |

Away（アプリ Off）と違い、こちらは「公開スイッチは On だが、non-private のチェックインが無い」状態。

### C. Embed snippet（想定）

```html
<iframe
  src="https://swarmtracker.example/embed"
  title="SwarmTracker"
  style="border:0;width:320px;height:48px"
></iframe>
```

または同一オリジンなら `div` + 小さなスクリプトで Compact を描画。

## ビジュアル方針（初期）

| 項目 | 方針 |
|---|---|
| サイズ | Compact 高さ roughly 40–48px、幅 280–360px |
| 背景 | 薄い紙色〜オフホワイトの単色ではなく、ごく薄い斜めグリッド or 柔らかいグラデーション |
| 文字 | 場所名は少し強め、時刻は小さく控えめ |
| 装飾 | 地図・ステッカー・統計は初期なし |
| モーション | 読み込み時にフェードイン、On→Off で場所がすっと消える程度（2動作まで） |

色の目安（実装時に CSS 変数化）:

- 背景: `#f3f0e8` → `#e7eef2` の弱いグラデーション（クリーム一色や紫グラデは避ける）
- テキスト: `#1c2430`
- Here ドット: `#0f7a6a`
- Away ドット: `#8b929a`

```text
│  SwarmTracker Admin            │
│                                │
│  Token: [************] [Unlock]│
│                                │
│  Public presence:  ● ON        │
│  [ Turn OFF ]                  │
│                                │
│  Preview                       │
│  ┌──────────────────────────┐  │
│  │ ● 朝霞駅 …   7/11 22:51 │  │
│  └──────────────────────────┘  │
└────────────────────────────────┘
```
